==================================================
   VIRALITY BOT - INSTALLATION FACILE
==================================================

Fais juste ca, dans l'ordre. Rien d'autre.

--------------------------------------------------
ETAPE 1 : Installe Node.js (a faire 1 seule fois)
--------------------------------------------------
Va sur : https://nodejs.org/fr
Clique le gros bouton vert, ouvre le fichier
telecharge, puis clique "Suivant" jusqu'au bout.

--------------------------------------------------
ETAPE 2 : Double-clique sur DEMARRER.bat
--------------------------------------------------
Il est dans ce meme dossier.
Une fenetre noire s'ouvre : LAISSE-TOI GUIDER.
Elle ouvrira le Bloc-notes toute seule pour que
tu colles ton token discord (le code secret du bot).

Si Windows affiche un ecran bleu "Windows a protege
votre PC" : clique "Informations complementaires",
puis "Executer quand meme". C'est normal.

--------------------------------------------------
ETAPE 3 : Laisse la fenetre noire ouverte
--------------------------------------------------
C'est elle, le bot. La fermer = eteindre le bot.

--------------------------------------------------
ETAPE 4 : Ouvre le dashboard
--------------------------------------------------
Dans Chrome, tape : http://localhost:3000
Mot de passe : celui que tu as ecrit dans le fichier
.env (ligne DASHBOARD_PASSWORD=...).

--------------------------------------------------
NOUVEAU : commandes rapides (page separee)
--------------------------------------------------
1) Dans Chrome, tape :
   http://localhost:3000/commandes
2) Mot de passe : bcko
3) Colle ton lien.
4) Clique "Envoyer et ping @Clipper".
L'embed part tout seul dans le salon commandes.
Cette page ne montre aucun autre reglage.

--------------------------------------------------
NOUVEAU : ticket automatique a l'arrivee
--------------------------------------------------
Quand un nouveau membre rejoint le serveur,
le bot lui cree automatiquement un ticket.
Pour choisir le type de ticket :
1) Ouvre le dashboard normal.
2) Clique l'onglet Tickets.
3) Dans "Ticket automatique a l'arrivee",
   choisis le type voulu.
4) Clique "Enregistrer l'arrivee automatique".

--------------------------------------------------
NOUVEAU : ouvrir un ticket depuis le dashboard
--------------------------------------------------
1) Ouvre le dashboard normal.
2) Clique l'onglet Tickets.
3) Cherche le pseudo du membre.
4) Choisis le type, par exemple Partenariat.
5) Clique "Ouvrir le ticket automatiquement".

--------------------------------------------------
BONUS : l'IA dans les tickets (optionnel)
--------------------------------------------------
1) Cree ta cle sur https://console.mistral.ai
   et colle-la dans le fichier .env, sur la
   ligne MISTRAL_API_KEY=...
2) Sur https://discord.com/developers/applications
   -> ton appli -> Bot -> active
   "MESSAGE CONTENT INTENT" -> Save Changes.
3) Dans le dashboard, onglet Tickets, allume
   "Activer l'assistante IA", enregistre,
   puis FERME la fenetre noire et relance
   DEMARRER.bat. C'est tout !
